# 变更 008: 新增 struct、enum、@FreeFunction、泛型语法基础

## 概述
本次变更引入四个核心语言特性：struct（值类型结构体）、enum（标记联合体）、@FreeFunction（透传顶层函数注解）和泛型语法基础（`<T>` 类型参数与实参），同时实现 Optional<T> 标准库容器。

## 新增特性

### 1. struct — 值类型结构体
- 栈分配的轻量级复合数据类型
- 支持字段声明和方法定义
- 无继承、无虚函数、无构造函数链
- 语法：`public struct Point { int x; int y; }`

### 2. enum — 标记联合体 (Tagged Union / ADT)
- 类型安全的联合体，每个 variant 可携带不同类型数据
- 支持泛型类型参数（`enum Option<T> { Some(T), None }`）
- 为 Optional<T>、Result<T,E> 等容器类型奠定基础

### 3. @FreeFunction — 透传顶层函数注解
- 将类静态方法导出为可直接调用的自由函数
- 命名空间内的方法需加命名空间前缀调用
- 编译期冲突检测：同名 @FreeFunction 方法跨类冲突时报错
- 错误报告包含源映射信息，支持 #include 后的正确行号定位

### 4. 泛型语法基础
- 类/struct/enum 支持 `<T1, T2, ...>` 类型参数声明
- 类型使用处支持 `<Type1, Type2>` 实参指定
- 类型系统新增 `Type::GenericParam` 和 `Type::Generic` 变体
- 采用单态化（monomorphization）实现（代码生成计划于 0.5.2.x）

### 5. Optional<T> 标准库
- `caylibs/Optional.cay` — 零开销 tagged union 容器
- 预定义特化：`OptionalInt`、`OptionalBool`、`OptionalDouble`
- API：`of()`、`empty()`、`isPresent()`、`isEmpty()`、`get()`、`orElse()`

## 技术细节

### struct 内存模型
```
struct Point { int x; int y; }
// offset 0: x (i32, 4 bytes)
// offset 4: y (i32, 4 bytes)
// total: 8 bytes, stack-allocated via alloca
```

### enum 运行时布局
```
┌─────────┬──────────────────────┐
│  tag:    │  payload (union):     │
│  i32     │  max(sizeof variants) │
└─────────┴──────────────────────┘
```

### @FreeFunction 命名规则
- 基本：函数名 → `class_name.method_name` 查找
- 命名空间：`ns::func_name` → 同时注册 `func_name` 和 `ns::func_name`

### 泛型命名规约
| 声明 | 实例化 | 内部符号 |
|------|--------|---------|
| `Optional<T>` | `Optional<int>` | `__Optional_i32` |

## 兼容性
- 向后兼容：所有新增语法均为纯增量，不影响现有代码
- 已有 keyword（`enum`、`struct`、`fn`）原预留但未使用，现正式激活
